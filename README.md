# Archivo Carmesí · Srta Vela HKT

Página personal estática en HTML, CSS y JavaScript, diseñada para publicarse con GitHub Pages.

## Archivos
- `index.html`: contenido y secciones de la página.
- `styles.css`: estilos adaptables a móvil y escritorio.
- `script.js`: interacción de la galería.
- `assets/`: imágenes utilizadas por la página.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `archivo-carmesi`.
2. Sube todos los archivos y la carpeta `assets` conservando la estructura.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, luego pulsa **Save**.
6. Espera a que GitHub Pages publique la web. La dirección aparecerá en esa misma sección.

La página no usa servidor ni base de datos. La galería abre las imágenes en una ventana ampliada. La fuente tipográfica usa Google Fonts y necesita conexión a internet; el resto de la página funciona como archivos estáticos.

Antes de publicar, revisa que las imágenes y la información sean apropiadas para un sitio público. El alias no revela por sí mismo tu identidad civil, pero cualquier imagen o dato que publiques podrá ser visto por visitantes.
